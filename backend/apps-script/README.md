# 간부자격 DAILY 완료기록 백엔드 설치·운영

현재 학생용 DAILY는 GitHub Pages에서 동작합니다. 중앙 완료현황을 모으려면 Google Apps Script Web App을 1회 연결합니다.

## 1. Apps Script 프로젝트 만들기
1. https://script.google.com 에 접속합니다.
2. **새 프로젝트**를 누릅니다.
3. 기본 `Code.gs` 내용을 모두 지웁니다.
4. 이 저장소의 `backend/apps-script/Code.gs` 전체를 붙여넣고 저장합니다.

## 2. setup() 최초 1회 실행
1. 상단 함수 선택에서 `setup`을 선택합니다.
2. **실행**을 누릅니다.
3. 최초 권한요청 화면에서 본인 Google 계정으로 권한을 허용합니다.
4. 실행 로그 또는 반환값에서 `sheetUrl`, `adminKey`를 확인합니다.
5. `adminKey`는 관리자만 보관합니다.

`setup()`은 Google Sheet를 만들고 다음 시트를 자동 생성합니다.
- `COMPLETIONS`: 학생 DAILY 완료기록
- `ROSTER`: 카카오방 참여자 명단

## 3. ROSTER에 200명 명단 넣기
- A열 `nickname`: 카카오방에서 확인할 이름/닉네임
- B열 `active`: 비워 두면 활성, `false`면 미완료 비교대상에서 제외
- C열 `memo`: 운영 메모

닉네임 중복은 피하는 것이 좋습니다. 동명이인이 있으면 `홍길동-수원`, `홍길동-01`처럼 구분합니다.

## 4. 웹 앱 배포
1. Apps Script 우측 상단 **배포 → 새 배포**
2. 유형 **웹 앱**
3. 실행 사용자: **나**
4. 액세스 권한: 수강생이 로그인 없이 제출해야 한다면 조직 정책이 허용하는 범위에서 **모든 사용자**를 선택
5. **배포**
6. 생성된 `.../exec` URL을 복사합니다.

조직 보안정책 때문에 '모든 사용자'가 보이지 않으면 그대로 진행하지 말고, 실제 수강생 계정 조건에 맞는 별도 인증방식을 정해야 합니다.

## 5. GitHub manifest에 API 연결
`daily_questions/manifest.json`의 아래 값을 수정합니다.

```json
"completion": {
  "enabled": true,
  "apiUrl": "여기에 Apps Script /exec URL"
}
```

저장 후 GitHub Pages가 갱신되면 학생이 DAY 인증화면을 만들 때 완료기록이 Google Sheet에도 저장됩니다.

## 6. 관리자 화면
GitHub Pages의 `/admin/` 페이지에서 다음 3개를 입력합니다.
- Apps Script `/exec` URL
- `setup()`에서 받은 `adminKey`
- 조회 날짜

그러면 **전체 명단 / 완료 / 미완료**, 완료자의 첫 시도 정답수, 모르겠음 수, 오답학습 수, 최종 재시험 통과 수, 인증코드를 확인할 수 있습니다.

## 7. 학생 학습 흐름
1. 오늘 링크 접속
2. 문제 상단에서 **과목 › 단원 › 챕터 › 세부포인트** 확인
3. 한 문제씩 풀이
4. 모르면 추측 대신 **모르겠음** 선택 가능
5. 최초 오답·모르겠음이면
   - 상세해설 확인
   - ANKI 직접회상 1차
   - 유사문제
   - ANKI 직접회상 2차
6. 오늘 기본문항 전부 완료
7. 최초 오답·모르겠음 문항만 **최종 오답 재시험**
8. 최종 재시험은 틀리면 다시 학습하고 같은 문항을 맞힐 때까지 반복
9. 최종 오답을 전부 맞히면 DAY 인증화면 생성
10. 카카오방 닉네임 입력 → 화면 캡처 → 카카오방 제출

## 8. 문항 수 확대
기본값은 20문항입니다.

`manifest.json`에서 특정 날짜의 plan 항목에 예를 들어 아래처럼 넣으면 해당 날짜만 확대됩니다.

```json
{
  "day": 22,
  "date": "2026-10-21",
  "theme": "전범위 · 숫자·기간·비율",
  "questionCount": 30
}
```

현재 상한은 `maxQuestionsPerDay: 60`입니다. DAILY 화면·진행률·오답학습·최종 재시험·완료인증은 실제 문항수를 자동으로 읽습니다.

## 9. 범위 배분 원칙
각 문제에는 `scope.subject / unit / chapter / part`를 저장합니다.

운영 원칙은:
- 하루 최소 4개 단원 이상
- 같은 단원 3문항 초과 연속 배치 지양
- 초기: 집중 약 60% + 누적·회전 약 40%
- 중기: 50% + 50%
- 시험 직전: 집중 약 40% + 누적·회전 약 60%
- 검증되지 않은 범위를 숫자를 맞추기 위해 억지로 출제하지 않음

이 배분은 공식 출제비중이 아니라 DAILY 학습 운영용입니다.

## 운영상 주의
- 인증 기준은 **점수**가 아니라 **완주 여부**로 운영하는 것이 좋습니다. 그래야 학생이 모르는 문제를 찍지 않고 '모르겠음'을 선택할 유인이 생깁니다.
- 닉네임과 완료기록을 수집하므로 수집 목적·항목·보관기간을 수강생에게 사전에 안내하세요.
- 네트워크·브라우저 문제로 기록이 누락될 수 있으므로, 실제 카카오방 인원 정리 전에 스크린샷과 중앙기록을 함께 확인하고 짧은 소명 절차를 두는 것이 안전합니다.
- 정적 웹앱은 시험감독 시스템이 아니므로 기술적으로 고의적 조작을 완전히 방지할 수는 없습니다.
